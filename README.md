# Рубежный контроль №1 — вариант 7

**Студент:** группа ИУ5-31Б, Ерицян С.  
**Предметная область:** микропроцессор — компьютер.

## Состав проекта

- `main.py` — программа на Python: классы предметной области, тестовые данные, связи 1:N и M:N, 15 запросов.
- `Отчет.pdf` — отчет с пояснением модели данных и алгоритмов, исходным кодом и результатами выполнения.

## Запуск

Требуется Python 3. Запустите из каталога проекта:

```bash
python3 main.py
```

Программа использует только стандартную библиотеку Python.

## Примечание по вариантам запросов

В исходном задании вариант 7 определяет предметную область. Наборы запросов отдельно обозначены буквами А–Д, без указания, какой из них нужно сопоставить номеру 7. Поэтому в программе и отчете приведена адаптация всех пяти наборов.
